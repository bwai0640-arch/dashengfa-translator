大声发划词翻译 0.4.0（Windows 桌面版）
========================================
作者：眼泪斷了线

一、软件功能

1. 在已启用的应用中双击英文单词，显示音标、中文直译，并播放标准美音或英音。
2. 拖动选中短语或句子，进行中英双向离线翻译，并可朗读英文。
3. 默认使用鼠标附近的迷你浮窗，也可以切换到完整大窗口。
4. 软件常驻 Windows 系统托盘，可切换模式、暂停取词、打开设置或退出。

二、安装

1. 完整解压安装包，不要只单独复制 EXE。
2. 双击“安装.cmd”。
3. 桌面和开始菜单会出现“大声发划词翻译”。
4. 开始菜单还会出现“大声发划词翻译 - 卸载”。
5. 启动后软件默认进入系统托盘，选中文字时才显示浮窗。

不需要安装 Python、Docker，不需要 API Key，也不依赖翻译网站。
安装程序会先检查主程序、词典、双向翻译模型、Piper/Kokoro 发音资源、图标和无障碍组件，并在独立临时数据目录中实际加载离线翻译与发音；检查通过后才替换旧版本。升级时若安装目录顶层存在不属于本软件的文件，会列出名称并停止，不会静默删除。

三、快捷键

- 默认连续轻按两次左 Alt：重新获取当前选区。读取到英文后立即播放美音；读取到中文时，本地翻译完成后播放对应英文译文。已有迷你窗会保持原选词位置，不跟随后来移动的鼠标。
- 默认 Alt+C：在迷你浮窗和大窗口之间切换。快捷键显示大窗口时不会主动抢走原应用焦点。
- 单击、长按、Alt+Tab、Alt+C、Ctrl+Alt、右 Alt/AltGr 和夹杂其他输入的两次 Alt 不会误触。
- 两项都可在“设置 → 全局快捷键”中修改；被其他程序占用或格式无效时会保留原设置。双击 Alt 只用于重新获取。
- 两个快捷操作也可在设置或托盘菜单中统一关闭。

四、迷你浮窗

- 宽度约 440 像素，高度随内容调整并保留底部操作区；过长译文可点“展开”查看全文。
- 原文、音标、US/UK 发音、直译、当前应用开关和操作按钮会完整显示。
- 点击浮窗外任意区域、按 Esc 或点“×”都能立即收起。
- 收起或关闭窗口会停止当前长句发音；点击“展开”切换大窗口时不会误停。
- “当前应用”开关可以直接关闭当前软件中的划词翻译。
- 点击“复制译文”可直接复制当前结果，点击“展开”进入大窗口。设置可从大窗口或托盘进入。

五、大窗口

- 发音区固定在最上方，不会被翻译内容挤掉。
- 可以编辑原文后手动翻译、复制译文、播放美音或英音。
- 关闭大窗口只会收进托盘；彻底退出请右键托盘图标选择“退出”。

六、应用设置

- 默认常用应用包括：Microsoft Word、Excel、PowerPoint、经典/新版 Outlook、OneNote；WPS 文字、表格、演示、PDF；Edge、Chrome、Firefox；Adobe Acrobat Reader、Adobe Acrobat、Foxit PDF Reader；QQ 和记事本。
- 微信（`wechat.exe` / `weixin.exe`）已取消取词支持，不会出现在应用列表中，也不能手动开启。
- 常用应用优先展示，调整过的应用会排在组内前面。
- “其他应用”可以一键全部开启或关闭，也可以展开后单独设置。
- 其他应用可以“设为常用”，自定义常用应用也能移回其他应用。
- “刷新正在运行的应用”会识别当前打开且有窗口的软件。
- “添加应用…”可以手动选择尚未运行的 EXE。

七、离线、速度与隐私

- 英汉词典和中英翻译模型都在本机运行，文档内容不会上传到翻译网站。
- 单词优先查本地词典；句子使用本地 OPUS 模型；翻译结果会缓存在本机。
- Word、PowerPoint、Excel 和经典 Outlook 优先使用各自的专用选区读取；经典 Outlook 覆盖独立邮件窗口、内嵌回复和普通阅读窗。
- Office、WPS、浏览器和文本型 PDF 在普通无障碍读取失败后，可从前台窗口根继续进行节点数、深度和耗时受限的选区探测，只读取当前选区，不读取整篇文档。
- 对需要兼容读取的应用，软件只在可以安全备份原剪贴板时短暂发送复制；微信已明确排除，不会尝试读取。
- 兼容读取只备份白名单内受支持且可完整重建的剪贴板格式；这不代表任意 Office/OLE 富格式都能安全还原。
- 遇到无法确认可安全还原的格式、虚拟附件、超过 64 MiB 的内容或无效剪贴板序号时，不会发送复制快捷键。
- 自动弹出的迷你窗和大窗口都不会抢走原应用焦点，划词后仍可直接使用 Ctrl+C。
- 取词期间若用户继续操作，或焦点、剪贴板发生变化，会取消本次读取并保留新内容。
- 密码输入框不会读取。

八、发音

- 设置中的“自动发音偏好”统一控制 US/UK 单击与双击、双击 Alt 自动朗读、短语/句子，以及中文译成英文后的朗读。
- 默认“优先速度”：US/UK 单击、双击 Alt 自动朗读和短语/句子使用 Windows 本地 Microsoft Zira / Hazel；US/UK 双击使用 AI。
- “优先自然音色”：US/UK 单击、双击 Alt 自动朗读和短语/句子使用 AI；US/UK 双击使用 Windows 本地 Microsoft Zira / Hazel。
- AI 独立英文单词使用 Piper：US 为 `en_US-lessac-high`，UK 为 `en_GB-cori-high`；AI 短语、句子和中文译出的英文使用 Kokoro：US 为 `af_bella`，UK 为 `bf_emma`。
- 双击会取消同一轮待定单击，不会先后播放两种后端。普通短句完整生成后播放；较长句子只在自然停顿处分段，并在安全缓冲足够时提前播放，否则等待整句完成。
- “慢速 / 标准 / 快速”只调整 Kokoro 句子速度；Piper 单词保持原版速度，Windows 本地语音不受影响。

如果 Windows 本地发音没有声音，请在 Windows“设置 → 时间和语言 → 语言和区域”中安装对应英语语言的“语音”组件。AI 资源缺失或损坏时，本次请求会安全回退到 Windows 本地语音，不会联网下载模型。

九、数据与升级

- 新数据目录：%LOCALAPPDATA%\DaShengFaTranslator
- 从 0.2.x 首次升级时，会复制旧设置和翻译缓存，但不会删除旧目录。
- 一次选择超过约 3000 个字符时不会自动翻译。

十、卸载

可从开始菜单点击“大声发划词翻译 - 卸载”，也可在完整解压的安装包中双击“卸载.cmd”。卸载默认保留设置和翻译缓存。卸载前会检查安装目录；若顶层存在用户自行放入的未知文件，会列出名称并停止，快捷方式也会保留。若要一并删除新旧用户数据，可运行：

powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -RemoveUserData
