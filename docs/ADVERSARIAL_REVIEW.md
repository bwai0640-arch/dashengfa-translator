# 对抗式审查

## 定义

本项目的“对抗式审查”不等于只读代码。审查者要假设一名故意刁难软件的真实用户正在操作：连续换词、乱按快捷键、拖到屏幕边缘、翻译途中关窗、占用剪贴板、破坏设置、缺少语音、强行中断安装，并寻找任何卡顿、闪退、误读、误删、按钮消失或无反馈。

能在隔离环境复现的操作必须固化成自动测试；必须接触真实 Office、PDF、QQ、系统托盘、SAPI 或 Windows 安装状态的场景，必须列入实机验收，不能用模拟结果冒充通过。微信已明确排除，不应再作为取词能力验收目标。

对发音、视觉、动画、可读性、响应感等由人的感官判断的产品承诺，自动测试只能验证技术前提。审查必须分别报告“技术契约”“黑盒任务行为”“真人感官结论”；没有实际听见或获得真人结论时，只能标记“感官验收待完成、产品承诺尚未完全验证”，不得宣称通过、修好或可发布。

## 自动化刁难场景

| 用户故意做什么 | 必须守住的结果 |
| --- | --- |
| A 词刚选中就改选 B，再改选 C | 只显示并朗读最新选区；旧翻译不得回弹。 |
| 翻译还在运行就点窗外、关闭、暂停或禁用当前应用 | 浮窗不复活，待处理发音取消，暂停后不再接收结果。 |
| 连点 US/UK、在单词与句子间快速切换、长句朗读中立即换词 | 只播放最新请求；实际后端严格服从当前自动发音偏好，不能因文本长度临时换音色；不丢失后续发音能力。 |
| 单击 US/UK 后在系统双击时间内完成第二击 | 识别为一次双击并抑制待定单击；速度模式只播放 AI，自然模式只播放 Microsoft Zira / Hazel，不先响或补响另一后端。 |
| 冷启动后立刻操作 US/UK，AI 仍在预热或其中一个预热失败 | 速度模式单击及自然模式双击直接进入 SAPI；需要 AI 的手势提升当前候选并让预热让路，界面和取词不阻塞。 |
| 快速交替单击 US、UK，再双击另一个按钮 | 最新仲裁代次胜出；旧生成不得迟到播放，微软语音与 AI 不重叠。 |
| 发音途中反复切换“慢速 / 标准 / 快速” | 下一请求只对 Kokoro 使用模型原生 `0.75/0.85/1.00`；Piper 始终保持原版 `1.00` 且不经过后处理，旧请求取消，SAPI 系统语速不被改写。 |
| Piper 模型或配置被替换，或运行时报告与模型配置不一致的采样率 | 最终 WAV 必须遵守模型固定的 22.05 kHz 契约；不一致、缺失或不可验证时安全回退 SAPI，不能只检查“采样率大于零”。 |
| 在句子 AI 生成期间关闭窗口、重新取词、切换偏好或切换为 SAPI | 分段生成在下一安全边界停止，未播放队列清空，旧音频不得迟到播放；状态只呈现已发生的分段、缓冲、取消或回退事实。 |
| 让前两段很快、后续段突然变慢 | 只有真实耗时/音频比预测仍安全时才可开播；预测不安全就等整句完成，不能播放到一半卡住或改播 SAPI。 |
| WAV 可解析、时长正确、纯音频率稳定且全部自动测试通过 | 只能说明技术前提成立；必须再用真实单词和句子盲听自然度、清晰度、音高、节奏和口音，未听不得签发产品通过结论。 |
| 连续启动、退出或打开多个窗口，故意撞上并行预热 | Piper/Kokoro 各自只预热一次，不在线程爆炸、退出卡死或 Tk 主线程阻塞。 |
| 让先启动的后端后完成，或让旧生成在新请求之后才返回 | 一行状态只显示真实阶段且保持最新代次；两个后端分别就绪，不倒退、不伪造百分比、不被迟到任务覆盖。 |
| 分别删除、截断或替换 Piper 模型、BERT、任一 CPU DLL、Kokoro 模型 | 对应 AI 单击及时回退 SAPI，另一后端仍可独立工作；不崩溃、不联网下载、不用错误文件继续推理。 |
| 在无显卡/无 Vulkan 的机器运行，或在装有高端显卡的机器运行 | 两种环境都固定使用 Piper CPU 后端；不探测或加载 Vulkan/CUDA/HIP，行为和资源契约一致。 |
| 按住 Ctrl、Shift、Win、Alt/AltGr 时完成鼠标选区 | 不注入兼容 `Ctrl+C`，用户自己的快捷键不被劫持。 |
| 单按、长按、右 Alt、Alt+Tab、夹杂其他键或缓慢按两次 Alt | 不误触；只有规定时间内两次干净的左 Alt 轻按才重新获取。 |
| 选词浮窗出现后把鼠标移到远处，再双击 Alt 重新获取 | 同一来源窗口继续使用原选词锚点，浮窗不追随鼠标跳走；首次取词或切换来源窗口仍采用新的安全位置。 |
| 快捷键被其他软件占用，或设置文件无法保存 | 保留旧快捷键，界面回滚并明确报错。 |
| 设置 JSON 截断、临时文件残留或主文件损坏 | 备份损坏文件；只恢复完整临时文件，否则关闭桌面取词后安全启动。 |
| 在左侧负坐标副屏、右侧副屏、窄工作区和各方向任务栏边缘划词 | 窗口留在鼠标所在工作区，按钮完整，不被任务栏吞掉。 |
| 剪贴板含图片、文件、HTML、Office/OLE 未知格式，或读取中被用户再次复制 | 只处理可完整重建的白名单格式；未知状态不注入复制，也不覆盖用户新内容。 |
| UIA 扫描超时、不完整、密码或无法判断安全性 | 一律安全失败，不以“尽量读到”为理由复制受保护内容。 |
| 托盘创建失败、第二实例启动、互斥锁创建失败 | 保留可见入口或明确错误，不出现无入口后台进程。 |
| 测试包缺模型、词典内部损坏、图标/DLL 文件头错误 | 安装接管前失败，旧版保持可用。 |
| 安装复制、标记写入、替换或卸载删除中断 | 只处理带严格产品标记的目录；可回滚或明确保留隔离残留，不误删用户文件。 |

相关回归分布在 `tests/test_watcher_lifecycle.py`、`test_selection_capture.py`、`test_translation_engine.py`、`test_window_positioning.py`、`test_ui_layout_contract.py` 与 `test_installer_safety_contract.py`。

## 必须实机验收

以下项目不能在不影响用户桌面的隔离测试中诚实宣称完成：

1. Word、PowerPoint、Excel、经典/新版 Outlook 与 WPS 全家桶的真实选区。
2. Chrome、Edge、Firefox 内置 PDF，以及 Adobe、Foxit、WPS PDF 的文本层选区；扫描件应明确失败。
3. QQ 的不同版本和自绘控件。若 UIA 无法明确确认安全，允许读取失败，但不得卡鼠标、闪退或破坏剪贴板；微信不在取词支持范围内。
4. 不同 DPI 的真实多显示器、自动隐藏任务栏和超长系统字体。
5. 在两种自动发音偏好下实际比较单词 Piper US/UK、短语/句子 Kokoro US/UK、长句安全缓冲播放，以及 Microsoft Zira / Hazel；覆盖 Kokoro 三档速度、快速切换、冷启动立即操作和 AI 故障回退。先把音频随机编号并隐藏后端/速度，由真人记录自然度、清晰度、音高、节奏、口音、首声延迟与是否卡顿；报告必须写明评价者和环境。若审查代理不能亲耳听见且没有真人结论，整体发音承诺保持未验收。
6. 在断网、无独立显卡、未安装 Vulkan/CUDA 的干净 Windows 用户或虚拟机中核实 CPU-only Piper、Kokoro 并行预热、首击延迟、界面响应和退出；再在有 GPU 的机器确认不会转用 GPU 后端。
7. SmartScreen、杀毒软件、策略锁定的快捷方式目录，以及虚拟机内的强杀安装/卸载恢复。

## 未经批准不实施的新设计

下列方向可降低剩余风险，但会改变架构或产品界面，必须先获得用户同意：

- 把 COM/UIA/兼容复制放进可超时销毁的独立辅助进程，隔离无法取消的原生调用。
- 增加翻译缓存关闭、清空和保留期限设置。
- 将自绘开关替换为完整原生无障碍控件，或给长设置页增加始终可见的滚动条。
- 为混合中英文选择增加手动方向或逐段语言识别。
