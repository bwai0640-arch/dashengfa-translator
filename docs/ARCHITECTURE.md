# 架构说明

## 目标

大声发划词翻译优先满足三个目标：响应快、发音入口明显、在弱网或无网环境中可用。网络不是核心依赖，选区文本默认不离开本机。

## 组件

| 组件 | 文件 | 职责 |
| --- | --- | --- |
| 桌面外壳 | `desktop_app.py` | 托盘、全局鼠标监听、窗口、应用白名单和设置页。 |
| 翻译核心 | `app.py` | ECDICT、CTranslate2、SentencePiece、缓存和 SAPI 发音。 |
| 资源 | `resources/` | 词典数据库、双向 OPUS 模型和应用图标。 |
| 构建 | `DaShengFaTranslator.spec` | 将 Python 运行时、依赖和资源打包为 Windows 文件夹版。 |

## 取词数据流

1. 全局鼠标监听只识别左键拖选或双击。
2. 读取前检查总开关与前台进程名是否在用户允许的应用列表中。
3. Word 使用 COM Selection；其他应用优先读取 Windows UI Automation TextPattern Selection。
4. 前两条路径失败且兼容读取开启时，软件发送一次复制快捷键。
5. 兼容读取先检查剪贴板格式：图片、文件、位图或图元文件会直接放弃；文本读取后恢复原文本。
6. 密码控件被识别后禁止进入兼容读取。
7. 有效文本进入单槽翻译队列；新的选择会替换尚未开始的旧请求。

## 翻译与发音

- 单个英文词优先查 ECDICT SQLite 数据库，返回音标和中文释义。
- 英文句子使用 `translate-en_zh-1_9`；中文文本按需加载 `translate-zh_en-1_9`。
- CTranslate2 使用 CPU int8 推理，结果写入本地 SQLite 缓存。
- 发音由 Windows SAPI 提供，按语言属性选择美音 `409` 或英音 `809`。

## 窗口模型

- 迷你窗为无边框置顶窗口，通过 `SWP_NOACTIVATE` 显示，避免抢走原应用焦点。
- 宽度固定为 440 像素；高度按内容请求尺寸和 DPI 在 188–238 像素之间调整。
- 全局单击落在迷你窗外时立即收起；窗内按钮不触发误关闭。
- 大窗口使用独立发音卡片，翻译区可伸缩，底部操作区保持可见。

## 设置与数据迁移

- 新数据目录为 `%LOCALAPPDATA%\DaShengFaTranslator`。
- 首次启动且新目录不存在时，只复制旧目录中的 `settings.json` 与 `translation-cache.db`。
- 旧目录不会被自动删除；只有用户显式运行带 `-RemoveUserData` 的卸载命令才清理新旧数据。

## 安全边界

- 不捕获未启用应用中的选区。
- 不读取密码控件。
- 不覆盖图片和文件剪贴板。
- 不把选区、缓存或日志上传到网络服务。
- 单次自动翻译上限为 3000 个字符。
