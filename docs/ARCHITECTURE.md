# 架构说明

## 目标

大声发划词翻译优先满足三个目标：响应快、发音入口明显、在弱网或无网环境中可用。网络不是核心依赖，选区文本默认不离开本机。

## 组件

| 组件 | 文件 | 职责 |
| --- | --- | --- |
| 桌面外壳 | `desktop_app.py` | 托盘、全局鼠标监听、窗口、应用白名单和设置页。 |
| 全局快捷键 | `hotkey_service.py` | 校验用户配置，并在独立 Win32 消息线程注册普通组合键；默认双击 Alt 委托给输入监听。 |
| 选区兼容层 | `selection_capture.py` | Word、PowerPoint、Excel、经典 Outlook 专用读取，有界 UIA 选区探测、应用时序和剪贴板并发保护。 |
| 运行策略 | `capture_runtime.py` | 按应用学习兼容读取等待时间。 |
| 翻译与发音核心 | `app.py` | ECDICT、CTranslate2、SentencePiece、缓存，以及 Piper、Kokoro、SAPI 发音路由。 |
| 资源 | `resources/` | 词典数据库、双向 OPUS 模型、Piper/Kokoro 离线发音资源和应用图标。 |
| 构建 | `DaShengFaTranslator.spec` | 将 Python 运行时、依赖和资源打包为 Windows 文件夹版。 |

## 取词数据流

1. 全局鼠标监听识别左键拖选或双击；同一输入监听以代次状态机识别干净的左 Alt 双击，普通组合键由原生热键线程投递轻量命令。两条路径都不在输入钩子中执行取词或 Tk 操作。
2. 读取前检查总开关与前台进程名是否在用户允许的应用列表中。
3. Word、PowerPoint、Excel 与经典 Outlook 使用各自的 COM 选区读取并复核前台窗口与选区稳定性；PowerPoint 仅接受 `ppSelectionText`，经典 Outlook 覆盖独立邮件窗口、内嵌回复和普通阅读窗的 WordEditor。
4. 专用路径失败后优先读取 Windows UI Automation TextPattern Selection。Office、WPS、浏览器、浏览器内置 PDF 与桌面 PDF 阅读器等复杂窗口在普通焦点/鼠标祖先链失败后，可从前台窗口根做节点数、深度和耗时均受限的后代探测；只调用 `GetSelection`，不读取整篇文档。
5. 前述路径失败且兼容读取开启时，软件仅把精确白名单内、受支持且可完整重建的 Win32 格式复制为托管 `str/bytes`，其中包括相应条件下的文本、HTML/RTF、PNG/DIB、真实文件列表和精确命名的 Chromium source URL / RFH token HGLOBAL 元数据；不保留裸 OLE/GDI 句柄。确认能够完整还原后才发送一次复制快捷键。
6. PowerPoint 与 QQ 使用各自的选区稳定与剪贴板等待时间。微信（`wechat.exe` / `weixin.exe`）已按产品决定排除，不会进入取词或兼容复制路径。兼容复制只在 UIA 安全状态明确为 `SAFE` 时允许，密码、超时、扫描不完整或未知状态一律停止。
7. 兼容读取只在焦点、输入代次、剪贴板所有者与序号仍匹配时进行；若其他操作产生了新内容则保留新内容。
8. 原剪贴板格式不支持安全快照、超过 64 MiB 或属于无本地文件列表的虚拟附件时，不发送复制快捷键；密码控件也禁止进入兼容读取。
9. 有效文本与选择代次一起进入单槽翻译队列；开始推理前用 45ms 合并快速 A→B→C 操作，只执行最新请求，模型始终单线程。失效通知与结果显示都排入 Tk 主线程并二次复核代次，旧翻译不能回显或触发新选区发音。

## 翻译与发音

- 单个英文词优先查 ECDICT SQLite 数据库，返回音标和中文释义。
- 英文句子使用 `translate-en_zh-1_9`；中文文本按需加载 `translate-zh_en-1_9`。
- CTranslate2 使用 CPU int8 推理，结果写入本地 SQLite 缓存。
- 设置持久化统一的 `auto_speech_preference`，缺字段或非法值迁移为默认 `speed`。`speed` 把 US/UK 单击、双击 Alt 自动朗读和短语/句子路由到 SAPI，把 US/UK 双击路由到 AI；`natural` 完全反转。中文选区译出的英文沿用该次自动朗读模式。
- Piper TTS `1.6.0` 在进程内使用 ONNX Runtime 的 CPU 执行提供程序；US 使用 `en_US-lessac-high`，UK 使用 `en_GB-cori-high`。应用将模型、配置、模型卡与 eSpeak 数据随包携带，合成的 WAV 固定为模型输出的 22.05 kHz；不联网下载模型，也不依赖 GPU。
- Kokoro 使用本地 ONNX int8 模型，US 为 `af_bella`，UK 为 `bf_emma`。Piper 与 Kokoro 都不启动网络服务、不占用端口，也不在运行时下载资源。
- Kokoro 只在句号、分号、冒号、逗号等自然语义停顿处分段，不按固定字符数硬切。普通短语和短句整段合成后播放；至少三个自然段的长句按顺序生成完整段，并用真实生成耗时、音频时长及剩余文本估算能否持续供给。只有至少两个完整段、累计约 5 秒音频且保守预测安全时才启动分段队列，否则等待整句完成后一次播放。播放开始后不改变后端。
- 按钮第一次按下会建立仅属于当前双击判定窗口的可取消 AI 候选。仲裁为 SAPI 时立即使候选失效；仲裁为 AI 时复用或继续候选。第二击取消待定单击，因此不会先响单击后端再响双击后端。
- “慢速 / 标准 / 快速”只映射到 Kokoro 短语与句子的模型原生速度 `0.75 / 0.85 / 1.00`。Piper 单词固定为原版 `1.00`，不做后处理变速；SAPI 双击发音的系统语速也不修改。
- 启动后以两个独立后台任务并行预热 Piper 与 Kokoro，并各自执行真实小样本推理。预热接受协作式让出信号；按钮候选、旧候选和旧请求按代次失效，最新正式 AI 请求优先。SAPI 使用独立 COM 线程，永远不获取 AI 合成锁。
- 发音区只保留一行阶段状态，由已发生的状态转换驱动：按钮候选、双击仲裁、并行预热、Piper/Kokoro 分别就绪、真实分段生成、累计缓冲、播放、取消或回退。不得用计时器推算或显示百分比；迟到任务不得覆盖较新的状态。
- 生成、回退与播放共用最新请求代次。可测试时序同时写入结构化日志：按钮按下、仲裁完成、AI 实际开始、各段完成、累计缓冲、实际播放、取消、回退及错误原因。
- 默认双击左 Alt（或用户设定的重新获取组合键）始终只产生“重新获取并自动美音”意图；具体 SAPI/AI 后端由统一偏好决定。英文直接播放，中文只播放同代次的英文译文。
- 关闭浮窗、大窗口或点击窗外会取消当前发音；迷你/大窗之间的纯模式切换不取消。

## 窗口模型

- 迷你窗为无边框置顶窗口，通过 `SWP_NOACTIVATE` 显示，避免抢走原应用焦点。
- 常规宽度为 440 像素；实际宽高按内容、DPI 与鼠标所在显示器的 `rcWork` 限制，支持副屏负坐标和不同方向任务栏，狭小工作区会自动缩小。
- 全局单击落在迷你窗外时立即收起；窗内按钮不触发误关闭。底部固定保留当前应用开关、“复制译文”和“展开”，设置从大窗口或托盘进入。
- 大窗口使用独立发音卡片，翻译区可伸缩，底部操作区保持可见；自动取词显示大窗口时也不激活窗口，用户从托盘或按钮主动打开时才正常聚焦。
- 默认 `Alt+C` 使用无激活路径显示大窗口；用户可修改该组合，托盘或界面按钮打开大窗口时仍可正常获得焦点。自动显示路径不抢走源应用焦点，因此划词后源应用的 `Ctrl+C` 仍可继续使用。

## 设置与数据迁移

- 新数据目录为 `%LOCALAPPDATA%\DaShengFaTranslator`。
- 默认双击左 Alt 与 `Alt+C` 都可修改；录制器与运行时使用相同的中断规则，新组合先完成格式与系统占用检查，再以事务方式保存，失败时恢复旧注册。
- 设置采用临时文件原子替换；保存失败会回滚界面和内存值，损坏的主设置会备份后以“桌面取词关闭”的安全状态启动，有效临时文件可恢复主设置。
- 默认常用应用为 Word、Excel、PowerPoint、经典/新版 Outlook、OneNote，WPS 文字/表格/演示/PDF，Edge、Chrome、Firefox，Adobe Reader/Acrobat、Foxit、QQ 与记事本。微信（`wechat.exe` / `weixin.exe`）不在应用列表中，也不能手动开启。
- 首次迁移只复制旧目录中的 `settings.json` 与 `translation-cache.db`；某项临时失败时不写完成标记，下次启动可重试缺失项。
- 旧目录不会被自动删除；只有用户显式运行带 `-RemoveUserData` 的卸载命令才清理新旧数据。

## 安全边界

- 不捕获未启用应用中的选区。
- 不读取密码控件。
- 兼容读取只处理白名单内受支持且可完整重建的剪贴板格式；任一未知 Office/OLE 格式、裸句柄、虚拟附件或超限内容使快照不完整时，整次兼容读取都会取消。
- 焦点、鼠标交互或剪贴板在等待期间发生变化时，不覆盖更新后的内容；兼容复制发出后只要用户继续操作，随后出现的剪贴板变化一律按用户内容保留。
- 所有兼容复制路径在准备阶段和实际注入 `Ctrl+C` 的最后一刻都复核物理 Ctrl、Shift、Alt/AltGr 与 Win 键。
- 不把选区、缓存或日志上传到网络服务。
- 单次自动翻译上限为 3000 个字符。

## 进程与部署

- 单实例使用当前登录会话的 Win32 命名互斥锁，不占用固定网络端口。
- 托盘后端启动失败时大窗口会保持可见并显示错误，避免程序无入口地后台运行。
- 安装包先在临时 `LOCALAPPDATA` 中验证身份、版本、资源、SQLite 词典完整性、真实词条、双向翻译，以及 Piper/Kokoro 离线发音资源与 CPU 运行时，再替换旧版；部署标记采用同目录原子写入和严格类型校验，未知顶层文件不得自动删除。
- 卸载先把正式目录同卷改名为严格标记的隔离目录，确认程序文件完全删除后才移除快捷方式；用户数据在任何删除前完成全量预检。
