## 发音路由与离线资源（8 项）

- [~] 40. AI 独立英文单词使用本地 CPU-only Piper；US 使用 `en_US-lessac-high`，UK 使用 `en_GB-cori-high`。
- [~] 41. AI 英文短语、句子及中文译出的英文使用本地 Kokoro，US 选择 `af_bella`，UK 选择 `bf_emma`。
- [x] 42. Windows 本地发音按 US/UK 使用 Microsoft Zira / Hazel；按钮双击会取消同轮待定单击，只按当前偏好播放一个后端，不等待或补播另一个后端。
- [~] 43. “慢速 / 标准 / 快速”只使用 Kokoro 的模型原生速度 `0.75 / 0.85 / 1.00`；Piper 单词固定保持原版 `1.00`，不得用播放加速或自制后处理拉伸伪造变速；该设置也不得改变 SAPI 的系统语速。
- [x] 44. 启动后并行后台预热 Piper 与 Kokoro 并执行真实小样本推理；预热、按钮判定窗口候选和旧请求必须向最新真实点击让路，SAPI 不等待 AI 锁。Piper/Kokoro 失败时只对当前 AI 请求回退 SAPI，不联网修复。界面只呈现真实阶段，不伪造百分比。

## 已实现的统一发音契约

- [x] 46. 设置中新增统一的“自动发音偏好”，默认值为“优先速度”。旧设置缺字段时迁移为默认值；它不是单独的双击 Alt 开关，而是一组一致的发音手势映射：
  - “优先速度”：US/UK 单击、双击左 `Alt` 后的自动朗读、以及短语/句子，均直接使用 Windows 本地 SAPI；只有 US/UK 双击才使用 AI。
  - “优先自然音色”：US/UK 单击、双击左 `Alt` 后的自动朗读、以及短语/句子，均优先使用 AI；US/UK 双击使用 Windows 本地 SAPI。
  - AI 的单词与句子仍按既有文本路由选择 Piper 或 Kokoro；本地发音仍按 US/UK 选择 Microsoft Zira 或 Hazel。中文选区译为英文后的自动朗读也遵循同一偏好。
- [x] 47. 偏好直接决定 AI 或本地后端，不采用字符数或等待秒数切换：速度优先立即本地发音；自然音色优先从头到尾等待 AI，只有模型不可用、失败或用户取消时才回退/停止。普通短语和短句整段生成后播放；长句只在自然语义边界分段，按真实生成耗时/音频时长预测，在至少两段且约 5 秒音频缓冲安全时提前播放，否则等待整句生成完成。切词、关窗、切换发音或偏好会使旧音频失效。
